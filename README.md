# ejeah-tools

A collection of lightweight utility tools built with [Astro](https://astro.build/) and [React](https://react.dev/).

## Tech Stack

- [Astro](https://astro.build/) — Static site generator & file-based routing
- [React](https://react.dev/) — Interactive tool components
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first styling
- [TypeScript](https://www.typescriptlang.org/) — Type safety

## Getting Started

```bash
# Install dependencies
yarn install

# Start development server
yarn dev

# Build for production
yarn build

# Preview production build
yarn preview
```
